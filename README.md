# Character Manager — TP3 (Java Visual SIH-6406)

## Deskripsi

Character Manager merupakan aplikasi berbasis Java untuk membuat dan mengelola karakter permainan. Program menerapkan konsep OOP, termasuk encapsulation, constructor, enum, serta validasi atribut karakter.
